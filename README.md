# IT Career Explorer

Учебное интерактивное приложение для исследования зарплат IT-специалистов. Интерфейс построен на Streamlit и Plotly. Python/Pandas-аналитику пользователь пишет самостоятельно, по одному заданию за раз.

## Запуск в Windows

Открой PowerShell в папке проекта:

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Адрес: http://127.0.0.1:8501. Оставь терминал открытым. Остановка сервера — `Ctrl+C`. Активировать окружение не требуется. Также можно запустить `./start.ps1`, если выполнение PowerShell-скриптов разрешено в системе.

Для установки с нуля (Python 3.13):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

`requirements.txt` фиксирует прямые зависимости. `requirements.lock.txt` содержит полный проверенный набор пакетов для Python 3.13 / Windows; для точного воспроизведения можно установить его вместо `requirements.txt`.

## Что уже работает

- Обзор: четыре показателя, тренд зарплат, рейтинг, гистограмма и boxplot.
- Специализации: выбор количества профессий, диапазоны по опыту и тепловая карта.
- Формат работы: круговая диаграмма, scatterplot и показатели категорий.
- Динамика: график по годам, рост год к году, таблица.
- Мои данные: вызов твоей функции, показ возвращённого DataFrame и подсказки при ошибках.
- Демопример: поиск, фильтр опыта, выгрузка видимых вымышленных строк в CSV.
- Мастерская: единственное текущее задание и карта разделов лабораторной.
- Переключение четырёх готовых демосрезов, средней/медианы, сброс фильтров. Plotly поддерживает подсказки, увеличение, скрытие серий через легенду и экспорт PNG.

Все демонстрационные значения вымышлены и записаны в `demo/fixtures.json`. Демосрезы переключают готовые результаты, а не рассчитывают аналитику. Образец строк в таблице не является источником сводных показателей макета. График истории показывает 2021–2025 для региона и формата выбранного среза; остальные показатели срезов США/Европа/удалёнка относятся к 2025 году.

## Твой первый шаг

Условия: [docs/task_01.md](docs/task_01.md). Рабочий файл: [analysis/loader.py](analysis/loader.py).

Самого датасета в исходной папке не было. Помести файл в `data/`, реализуй `load_dataset(path)`, затем в приложении открой **Мои данные → Загрузить моим кодом**. Функция перечитывается с диска при нажатии кнопки. Реальные данные пока отображаются только на этой странице; остальные графики честно остаются демонстрацией.

Состояние загруженной таблицы и прогресс задания сохраняются в сессии браузера. После нового сеанса загрузи таблицу снова. Файлы кода и датасет сохраняются на диске.

## Структура

```text
app.py                   Навигация и запуск интерфейса
ui/                      Компоненты, оформление, графики, адаптер функций
demo/fixtures.json       Готовые вымышленные результаты
demo/provider.py         Выбор демопримеров без Pandas-агрегаций
analysis/loader.py       Твоя функция загрузки (пока пустой каркас)
data/                    Твой настоящий датасет
docs/task_01.md           Единственное выданное задание
docs/lab_requirements.md  Требования исходного документа
tests/test_interface.py   Проверки интерфейса и контракта интеграции
AGENTS.md                Правила сотрудничества
.streamlit/config.toml   Тёмная тема и локальный сервер
```

`analysis/` принадлежит пользователю: ассистент не исправляет и не дописывает аналитический код самостоятельно. Для текущего этапа в каркасе намеренно стоит `NotImplementedError`.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m pip check
```

Проверки подменяют ответы функции на время теста и не изменяют файлы `analysis/`. Группировок, чтения настоящего датасета и решений лабораторной в них нет.

Справочники интерфейса: [Streamlit Plotly charts](https://docs.streamlit.io/develop/api-reference/charts/st.plotly_chart), [Streamlit AppTest](https://docs.streamlit.io/develop/api-reference/app-testing/st.testing.v1.apptest), [Plotly](https://plotly.com/python/).
