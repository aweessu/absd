# Связь с лабораторной работой 12

Источник: `Lab 12- Mini project.docx`, прочитаны текст и все шесть встроенных иллюстраций с примерами кода. Оригинал сохранён без изменений.

Документ предлагает датасет с Kaggle и указывает имя `global_tech_salary.txt`. Ссылка на конкретный датасет в документе отсутствует. В папке проекта датасета нет.

Во встроенном примере загрузки используется разделение табуляцией. Пример объединения таблиц также использует `salary_currency`: для полного повторения этого этапа понадобится и этот столбец. Эти особенности нужно сверить с выбранным настоящим файлом.

## Требования документа

1. Загрузка и первичный осмотр: `head`, `info`, `describe`, пропуски и дубликаты.
2. Преобразования: разделение на таблицы зарплат и метаданных, объединение столбцов через `concat`, `melt`, сводная таблица по опыту и размеру компании, добавление строк через `concat`, stack/unstack.
3. Агрегации: средняя зарплата по профессиям, медиана по опыту, страна проживания с максимальной зарплатой, несколько агрегатов одновременно, группировка по опыту и размеру компании.
4. Графики: гистограмма, boxplot по опыту, топ-10 профессий, scatterplot зарплата/удалённость, тепловая карта по опыту и размеру компании.
5. Временные ряды: перевод `work_year` в даты, средняя зарплата по годам, график тренда, изменение год к году.

В документе приведены примеры на Seaborn/Matplotlib. По просьбе пользователя интерфейс использует Streamlit и Plotly, сохраняя смысл визуализаций.
