# Задание 1 — загрузить датасет

**Зачем:** приложение должно получить таблицу из файла. Это первая точка соединения твоего кода с интерфейсом.

В `analysis/loader.py` реализуй одну функцию `load_dataset(path)`.

- Вход: `path` — строка с путём к CSV/TXT-файлу.
- Выход: `pandas.DataFrame` с данными файла.
- Функция должна **возвращать** таблицу, а не только печатать её.
- На этом этапе не очищай, не фильтруй и не группируй данные.

1. Помести настоящий файл в `data/`. Если файла из лабораторной нет, выбери подходящий датасет на Kaggle с полями из `data/README.md`.
2. Посмотри первые строки в текстовом редакторе: чем отделены столбцы и есть ли строка заголовков? Для исходного файла в документе указана табуляция; для другого датасета формат может отличаться.
3. Реализуй функцию и сохрани файл.
4. Открой **Мои данные**, укажи путь и нажми **Загрузить моим кодом**.

**Критерий готовности:** приложение показывает твою таблицу с осмысленными названиями отдельных столбцов. Статус первого задания становится «Выполнено» после успешного получения непустого DataFrame. Проверь сам, что все поля не попали в один столбец.

Если застрянешь, первая подсказка: найди в Pandas функцию для чтения текстовой таблицы; обрати внимание на параметр разделителя. Готового решения в проекте нет.

Когда таблица появится, сообщи об этом и покажи свою функцию. Следующее задание получишь после проверки этого результата.
