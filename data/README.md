# Настоящий датасет

Помести сюда `global_tech_salary.txt` из лабораторной или подходящий CSV с зарплатами IT-специалистов. Самого датасета в исходной папке проекта не было.

Файлы данных исключены из Git. Демонстрационные данные хранятся отдельно в `demo/fixtures.json` и не подходят для выводов о реальном рынке.

Расширение `.txt` не определяет разделитель: посмотри первые строки файла в редакторе, прежде чем его загружать.

Ожидаемые для дальнейшей лабораторной поля: `work_year`, `experience_level`, `employment_type`, `job_title`, `salary`, `salary_currency`, `salary_in_usd`, `remote_ratio`, `employee_residence`, `company_location`, `company_size`. `salary_currency` используется во встроенном примере объединения таблиц из документа.

Для файла из лабораторной в документе показан разделитель табуляции. Если выбираешь другой файл, проверь его фактический формат.
